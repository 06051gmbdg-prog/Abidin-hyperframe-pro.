# Video: Cara pindah domisili KTP

Skrip (`script.json`), rencana adegan dan generator (`build.mjs`). Semua cue terkunci ke kata di suara, bukan detik.

Render lewat GitHub Actions: tab **Actions** -> **render-video** -> **Run workflow**.
Butuh secret repo `ELEVENLABS_API_KEY`. Hasil: cabang `renders-pindah-ktp` (`video.mp4`, `contact-sheet.png`).

Sumber isi: ANTARA (cara dan syarat pindah KK, 2025) dan Metro TV (pindah domisili tanpa surat RT/RW, 16 Okt 2025),
mengacu Permendagri 108/2019. Periksa ke Dukcapil setempat sebelum dipublikasikan.
