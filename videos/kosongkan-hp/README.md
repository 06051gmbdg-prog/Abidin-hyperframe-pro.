# Video: Cara mengosongkan ruang di HP

Skrip (`script.json`), rencana adegan dan generator (`build.mjs`). Cue terkunci ke kata di suara.
Render: tab **Actions** -> **render-video** -> isi `video` = `kosongkan-hp`. Butuh secret `ELEVENLABS_API_KEY`.
Hasil: cabang `renders-kosongkan-hp`.

Sumber: Apple Support (Free up storage on iPhone), panduan Files by Google (How-To Geek), Make Tech Easier (Android),
ITPro (WhatsApp Manage storage, 2020). Nama menu bisa berbeda per merek dan versi; cek di ponsel sebelum dipublikasikan.

USB 3.2 Gen 1, dua konektor (Type-C & Type-A), baca hingga 130 MB/detik (model 64–256 GB), kapasitas 32–256 GB. Tidak ada harga di video.
