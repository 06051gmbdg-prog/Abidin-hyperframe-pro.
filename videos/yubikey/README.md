# Video: akun tetap bisa dibobol? + YubiKey 5 Series (afiliasi)

Template ilustrasi + overlay. Isi: 3 langkah (password unik, verifikasi dua langkah, kunci keamanan fisik), lalu contoh produk YubiKey 5 Series.
Klaim produk hanya dari halaman Yubico (FIDO2, U2F, OTP, smart card; USB-A/USB-C/NFC/Lightning; tanpa baterai, tahan air) dan judul listing.
Gambar adalah ilustrasi generik tanpa merek (diberi lencana ILUSTRASI), bukan foto produk. Tidak ada harga di video.
`brand` di storyboard.json dikosongkan: isi nama channel Anda jika mau tampil watermark.

## Urutan menjalankan (setelah saldo fal.ai terisi)
1. Actions → **fal-images** → `video` = `yubikey`, `dry` = `yes` → Run (gratis, hanya menampilkan rencana dan perkiraan biaya: 7 gambar, sekitar US$1,33).
2. Run lagi dengan `dry` = `no` (berbayar). Gambar tersimpan otomatis di `videos/yubikey/assets/img`.
3. Kabari saya agar gambarnya saya periksa dulu (gaya dan tidak ada teks salah) sebelum render.
4. Actions → **render-video** → `video` = `yubikey` → Run workflow.
